# contrailgolf.app

Public website for Contrail (iPhone golf shot tracer): home, support and privacy pages.

- Pushes to `main` deploy automatically to https://contrailgolf.app (Cloudflare Workers, static assets in `public/`).
- `/support` and `/privacy` are linked from the App Store, so they must always work.
- Coding agents: read `AGENTS.md` first.
